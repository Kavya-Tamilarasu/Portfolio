## 👋 About the Project

This project is a modern, responsive personal portfolio designed to showcase **Kavya T's academic background, technical skills, internships, projects, certifications, and professional profiles**.

The portfolio also includes an **AI-powered Portfolio Assistant** that allows visitors to ask natural-language questions about Kavya's:

- 🎓 Academic background
- 💻 Technical skills
- 🚀 Projects
- 🏢 Internship experience
- 🛠️ Technologies
- 📜 Certifications
- 📬 Professional information

Instead of searching through multiple sections manually, visitors can simply ask the AI assistant a question.

### Example

> **Visitor:** Tell me about Kavya's Campus Connect project.

> **AI Assistant:** Provides a relevant explanation of the Campus Connect project based on the portfolio information.
